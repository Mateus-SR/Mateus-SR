## Projetos em destaque

### 01 / Busca Bus

Aplicação de monitoramento de ônibus para o transporte urbano
de São Paulo. O projeto utiliza a API Olho Vivo da SPTrans.
A nova versão trabalha com React/Next.js e comunicação
em tempo real via Socket.IO.

- [Abrir demonstração](https://busca-bus-web.onrender.com/)
- [Ver código-fonte](https://github.com/Mateus-SR/Busca-Bus-React)

### 02 / La Casa de Sacola

Projeto de e-commerce voltado à apresentação e comercialização
de sacolas personalizadas. Uma aplicação que explora o uso
da tecnologia para atender a uma necessidade comercial real.

A demonstração vinculada é um ambiente de teste.

- [Abrir demonstração de teste](https://la-casa-de-sacola-test.vercel.app/)
- [Ver código-fonte](https://github.com/Mateus-SR/La-Casa-De-Sacola)
